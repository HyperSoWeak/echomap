主題：AI Agent 核心概念

【使用者 Prompt／使用者需求】
我想從零開始理解 AI Agent 是什麼，以及它和一般聊天機器人、自動化腳本有什麼不同。我希望學會 Agent 如何接收目標、理解環境、拆解任務、選擇工具、記住重要資訊、檢查結果，並在遇到風險或不確定情況時請求人類協助。我沒有人工智慧或程式設計背景，每天可以用耳機學習約二十分鐘。請使用規劃旅行、整理信件、查詢資料與客服助理等生活化例子，搭配短課程和口頭練習。最後，我希望能設計一個安全、可驗證的簡單 AI Agent 工作流程。

【五個簡單的小問題】
1. AI Agent 和一般問答系統最大的差別可能是什麼？
   A. Agent 能為目標規劃並執行多個步驟
   B. Agent 一定有機器人的身體
   C. Agent 永遠不會犯錯

2. Agent 要查詢即時天氣，最適合怎麼做？
   A. 使用可靠的天氣工具取得資料
   B. 只靠記憶猜測
   C. 隨機產生答案

3. Agent 準備替使用者寄出重要信件前，應該優先做什麼？
   A. 顯示內容並取得確認
   B. 不經檢查立刻寄出
   C. 把信件永久刪除

4. 工具執行失敗時，Agent 應該怎麼做？
   A.辨認錯誤、嘗試安全替代方案或請求協助
   B. 假裝已經成功
   C. 一直重複相同操作

5. 你最想先設計哪一種 Agent？
   A. 資料蒐集與摘要助理
   B. 行程規劃助理
   C. 任務追蹤與提醒助理
